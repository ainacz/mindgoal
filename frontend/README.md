# Фронтенд «Маршрут»

Telegram Mini App: React 18 + TypeScript + Vite + Tailwind.

```bash
npm install
cp .env.example .env
npm run dev
```

Открывается и в обычном браузере: обёртка над Telegram WebApp падает
на заглушки, если мессенджера рядом нет. Для проверки внутри Telegram
нужен https — подними туннель (`cloudflared tunnel --url http://localhost:5173`)
и укажи адрес в @BotFather → Bot Settings → Menu Button.

## Где что

| Путь | Что внутри |
|---|---|
| `src/components/Graduation.tsx` | шкала на 90 делений — подпись всей системы |
| `src/components/` | остальные общие блоки: шторка, чек-лист, таббар |
| `src/screens/` | три экрана и мастер создания цели |
| `src/lib/telegram.ts` | initData, вибрация, подтверждения |
| `src/api.ts` | все вызовы бэкенда, голый fetch |
| `src/useResource.ts` | загрузка и перезагрузка, 25 строк вместо React Query |
| `tailwind.config.ts` | все токены цвета и шрифта |

## Правила дизайн-системы

Одна заливка на экран — главная кнопка. Бирюзовый только для текущего дня
и экрана генерации. Латунь только для стрика. Никаких карточек: структуру
держат волосяные линии. Никаких эмодзи и зачёркиваний.

Шестнадцатеричных цветов в компонентах быть не должно — только токены
из `tailwind.config.ts`. Исключение одно: `Graduation.tsx`, где цвет
уходит в атрибут SVG.
